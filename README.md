# Low-Cost-Myoelecrtic-Prosthetic-Arm

Low-Cost Myoelectric Prosthetic Arm Using AI, ML & Cloud Computing

This project develops a software-based AI system for myoelectric prosthetic arm control using EMG datasets from Kaggle. The EMG signals are preprocessed, features are extracted, and machine learning/deep learning models are trained to classify different intended hand movements. The project focuses on a low-cost approach without physical hardware, with cloud computing used for model training/deployment and performance analysis.

Key Features
EMG dataset collection from Kaggle

Data preprocessing and feature extraction

Machine Learning/Deep Learning model training

Hand movement classification

Model evaluation using accuracy, precision, recall, and F1-score

Result visualization and analysis

Cloud-based model execution/deployment

Technologies: Python, Pandas, NumPy, Scikit-learn, TensorFlow/Keras, Matplotlib, Google Colab/Cloud Computing.
